# PLP Python Week 5 — Countdown, Guessing Game & Loop Patterns

`countdown.py` — Counts down from a number entered by the user using a while loop.

`guess_game.py` — Runs a guessing game using a while loop, conditionals, and an attempt counter.

`spell_it_out.py` — Uses for loops to print each letter of a word and number each letter.

I would use a while loop when I want a program to keep repeating until a condition becomes false. I would use a for loop when I want to go through each item in a sequence, such as the letters in a word.
