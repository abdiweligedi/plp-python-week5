# Password Generator & Your Own Module

`password_generator.py` uses Python's `random` and `string` modules to generate random passwords of different lengths.

`helpers.py` contains functions for calculating the number of tables needed and creating welcome messages.

`main.py` imports the `helpers` module and uses its functions to display a welcome message and calculate tables needed.

This assignment demonstrates how Python modules can be imported and used in programs. It also demonstrates using `if __name__ == "__main__":` to control code that runs when a module is executed directly.
